# 🏥 Hospital Management System

A simple Hospital Management System designed to manage hospital-related information such as patients, doctors, appointments, and medical records through a user-friendly web interface.

## 🚀 Features

- Patient management
- Doctor management
- Appointment management
- Patient medical records
- Hospital database management
- User-friendly web interface
- Add, update, view, and delete records
- SQLite database integration

## 🛠️ Technologies Used

- **Python**
- **HTML**
- **CSS**
- **SQLite**
- **Git & GitHub**

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/hospital-management-system.git
```

2. Open the project folder:

```bash
cd hospital-management-system
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open the application in your browser:

```text
http://127.0.0.1:5000
```
